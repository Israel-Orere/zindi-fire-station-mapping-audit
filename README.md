# Fire-station mapping audit

Reproducible evidence for the Zindi Bias Bounty Mapping Equity Challenge.

**Key finding:** OSM-mapped fire-station sites in rural and more wildfire-exposed areas had fewer nearby Overture fire-department listings. Porum and Westport illustrate supported cases where a local building is mapped but its department listing is elsewhere.

The reproducibility archive contains cached comparison evidence and scripts. Original large challenge inputs are downloaded separately and verified against the included manifest. Snapshot: Overture 2026-08-19.0; OSM historical state 2026-08-01. Texas excluded; Eastern Washington supplementary.

These are map-record comparisons, not an operating-station census or evidence of observed response failures. Code: MIT. Original narrative and plots: CC BY 4.0. OpenStreetMap-derived data: ODbL, with provider attribution retained in the methodology.
